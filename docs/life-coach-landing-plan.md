# 라이프 코치 랜딩페이지 기획서 (이메일 DB 수집용 원페이지)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 무료 자료(리드마그넷)를 대가로 잠재고객 이메일 수집 |
| 형태 | 스크롤형 원페이지 (섹션 7개 + 폼 2회 노출) |
| 핵심 전환 액션 | 이메일 입력 → 무료 자료 자동 발송 |
| 목표 전환율 | 방문자 대비 이메일 등록 20~35% (광고 유입 기준) |
| 유입 채널 | 인스타그램 프로필 링크, 릴스/스토리 광고, 블로그, 유튜브 설명란 |

## 2. 타깃 페르소나

- **연령/상황**: 28~45세, 직장인 또는 프리랜서. "열심히 사는데 방향을 모르겠다"는 정체감을 느끼는 사람
- **심리 상태**: 번아웃 직전, 이직/커리어 전환 고민, 자존감·습관·목표설정에 대한 갈증
- **행동 특성**: 자기계발 콘텐츠를 소비하지만 실행이 안 됨. 유료 코칭은 부담스러워 "무료로 먼저 맛보고 싶은" 단계
- **핵심 니즈**: "내 상황을 정리해주고, 당장 해볼 수 있는 구체적인 것"

## 3. 리드마그넷 (무료 자료) 제안

전환율은 자료의 매력도가 절반을 결정합니다. 아래 중 하나를 선택하거나 조합:

1. **(추천) 「인생 방향 점검 워크북」 PDF** — 30분 셀프 코칭 질문 15개 + 작성 예시. "코칭을 미리 체험"하는 느낌이라 본 상품 연결이 자연스러움
2. 「번아웃 자가진단 체크리스트 + 회복 루틴 7일 플랜」 — 문제 인식이 강한 타깃에게 클릭률 높음
3. 「목표를 현실로 만드는 90일 플래너 템플릿」(노션/PDF) — 실용성 어필

> 자료 제목은 결과를 약속하는 형태로: "○○하는 법"보다 "○일 만에 ○○되는" / "○가지 질문으로 ○○ 찾기"

## 4. 페이지 구조 (와이어프레임)

스크롤 순서대로. **폼(CTA)은 히어로와 최하단 2곳 배치**, 모바일에서는 하단 고정 CTA 버튼 추가.

### ① 히어로 (First View)
- **헤드라인**: 타깃의 고민을 정면으로 + 자료의 결과 약속
  > 예: "열심히는 사는데, 방향이 맞는지 모르겠다면 — 15개의 질문으로 당신의 다음 챕터를 찾아드립니다"
- **서브카피**: "현직 라이프 코치가 실제 세션에서 쓰는 셀프 코칭 워크북, 지금 무료로 받아보세요"
- **폼**: 이메일 입력 1칸 + 버튼 ("무료 워크북 받기") — 입력 필드는 이메일 1개만 (필드가 늘수록 전환율 하락)
- **보조 요소**: 자료 목업 이미지(PDF 표지 3D 목업), "이미 ○○○명이 받아갔어요" 소셜프루프 한 줄

### ② 문제 공감 (Pain)
- 타깃이 속으로 하는 말을 그대로 나열 (3~4개 카드)
  > "아침에 일어나면 이유 없이 무기력해요" / "남들과 비교하다 하루가 끝나요" / "계획은 세우는데 3일을 못 가요"
- 마무리 한 줄: "의지의 문제가 아니라, **방향이 정리되지 않았기 때문**입니다"

### ③ 해결 제시 = 자료 소개 (What's Inside)
- 워크북 내부 미리보기 이미지 2~3장 (실물감이 신뢰를 만듦)
- 구성 불릿 4~5개: "Part 1. 지난 1년 돌아보기 질문 5개 / Part 2. 나의 가치관 지도 그리기 / …"
- 각 불릿은 "무엇"이 아니라 **"하고 나면 얻는 것"** 중심으로 작성

### ④ 코치 소개 (Authority)
- 사진 + 한 문단 스토리: 자격/경력 나열보다 "나도 같은 문제를 겪었고 이렇게 빠져나왔다" 서사
- 신뢰 지표 한 줄: 누적 코칭 시간, 수료 자격(KAC/KPC 등), 기업 강의 이력 등 팩트 2~3개

### ⑤ 후기 (Social Proof)
- 코칭/자료 이용자 후기 3개. 실명 이니셜 + 직업 + 구체적 변화 수치·문장
  > "질문 7번에서 울컥했어요. 3년 만에 처음으로 내가 뭘 원하는지 적어봤습니다" — 김○○, 34세 마케터
- 카카오톡 캡처 스타일이 텍스트 카드보다 진정성 높음

### ⑥ 받는 방법 안내 (How)
- 3스텝 아이콘: "이메일 입력 → 받은편지함 확인 → 30분 워크북 작성"
- 마찰 제거 문구: "스팸 없음 · 언제든 구독 해지 가능 · 자료는 1분 안에 도착"

### ⑦ 최종 CTA + 푸터
- 헤드라인 변주: "당신의 다음 챕터, 오늘 30분이면 시작됩니다"
- 이메일 폼 (히어로와 동일)
- 푸터: 상호/대표자/이메일, **개인정보처리방침 링크**, 저작권

## 5. 폼 & 전환 설계

- **필드**: 이메일 1개 (이름은 선택 — 뉴스레터 개인화가 필요하면 추가하되 '선택' 표기)
- **버튼 카피**: "제출"·"구독" 금지 → **얻는 것을 쓰기**: "무료 워크북 받기", "내 질문지 받아보기"
- **개인정보 동의**: 체크박스 + "개인정보 수집·이용에 동의합니다 (수집항목: 이메일 / 목적: 자료 발송 및 뉴스레터 / 보유기간: 동의 철회 시까지)" — 개인정보보호법상 필수
- **제출 후 (Thank You)**:
  - 완료 페이지 or 인라인 메시지: "메일함을 확인하세요! (프로모션 탭도 확인)"
  - **업셀 한 줄**: "자료가 도움됐다면, 1:1 무료 진단 세션(20분)도 신청해보세요" → 캘린더 예약 링크. DB 수집 페이지에서 바로 다음 퍼널로 연결하는 지점
- **모바일**: 화면 하단 고정 CTA 버튼 → 탭 시 폼으로 스크롤

## 6. 카피라이팅 원칙

1. 헤드라인은 "코칭 소개"가 아니라 **타깃의 언어로 쓴 고민 + 결과 약속**
2. "무료"를 3회 이상 반복 노출 (히어로, 자료 소개, 최종 CTA)
3. 숫자 사용: "15개의 질문", "30분", "7일" — 구체성이 신뢰
4. 희소성/긴급성은 과하지 않게 (허위 마감은 역효과). 쓴다면 "이번 달 뉴스레터 구독자에게만 보너스 템플릿 추가" 정도

## 7. 디자인 가이드

- **톤**: 따뜻하고 차분한 신뢰감 — 크림/베이지 배경 + 딥그린 또는 테라코타 포인트 1색
- **타이포**: 국문 세리프 제목(예: 마루부리) + 고딕 본문(프리텐다드) 조합, 제목은 크게
- **사진**: 스톡 느낌 배제. 코치 실제 인물 사진 + 워크북 실물/목업
- **레이아웃**: 1컬럼 중심, 섹션당 메시지 1개, 모바일 퍼스트 (유입 90%가 모바일 예상)
- **로딩 속도**: 이미지 WebP, 3초 내 첫 화면 — 광고 유입 이탈 방어

## 8. 기술 스택 & 운영

| 영역 | 제안 |
|---|---|
| 페이지 구현 | 본 저장소 스택 그대로 (Vite + React + Tailwind) 정적 원페이지 |
| 이메일 수집/발송 | 스티비(국내, 자동화 시퀀스 지원) 또는 ConvertKit / Mailchimp — 폼 API 연동 or 임베드 |
| 자동화 | 등록 즉시 자료 발송 메일 → 2일 후 활용 팁 메일 → 5일 후 무료 진단 세션 제안 (3통 웰컴 시퀀스) |
| 분석 | GA4 + Meta Pixel (광고 리타게팅), 전환 이벤트: 폼 제출 |
| A/B 테스트 | 1순위 헤드라인, 2순위 리드마그넷 제목, 3순위 버튼 카피 |

## 9. 성과 지표 (KPI)

- 방문 → 이메일 등록 전환율 (목표 20%+)
- 자료 발송 메일 오픈율 (목표 60%+, 더블 확인 문구로 개선)
- 웰컴 시퀀스 → 무료 진단 세션 신청률 (목표 5~10%)
- 광고 유입 시 리드당 비용(CPL)
