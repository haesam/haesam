# 성인 진로상담사 무료자료 신청 랜딩페이지 기획안

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 무료자료(리드마그넷) 신청을 통한 이메일 리스트 확보 |
| 형태 | 원페이지 랜딩페이지 (스크롤형) |
| 타깃 | 진로 전환·재취업·커리어 방향을 고민하는 성인 (28~45세 직장인 중심) |
| 핵심 전환 행동 | 이메일 입력 → 무료자료 신청 완료 |
| 성공 지표 | 방문자 대비 이메일 제출 전환율 (목표 10~20%) |

## 2. 타깃 페르소나

- **A. 이직/전직 고민형 (30대 직장인)**: "지금 회사가 맞는지 모르겠다. 옮기고 싶은데 뭘 해야 할지 모른다."
- **B. 경력단절/재도전형 (30~40대)**: "다시 일하고 싶은데 어디서부터 시작해야 할지 막막하다."
- **C. 번아웃/방향상실형**: "열심히는 살았는데 내 커리어에 확신이 없다."

공통 심리: **막막함 + 혼자 고민 + 검증된 가이드가 필요함** → 랜딩 카피는 이 감정을 정확히 짚는 것이 핵심.

## 3. 무료자료(리드마그넷) 제안

예시 (하나 선택 또는 조합):
- 『커리어 방향을 3일 만에 정리하는 셀프 진단 워크북 (PDF)』
- 『이직 전 반드시 점검해야 할 12가지 체크리스트』
- 『나에게 맞는 직업을 찾는 5단계 로드맵』

> 자료명은 "구체적 숫자 + 결과 약속" 구조가 전환율이 높음.

## 4. 페이지 구조 (섹션별 기획)

스크롤 순서대로. **이메일 폼은 상단(히어로)과 하단 총 2회 노출.**

### ① 히어로 (First View) — 전환의 70%가 여기서 결정
- **헤드라인**: 타깃의 고민을 그대로 언급
  - 예: "커리어, 이대로 괜찮을까요? 방향부터 정리하세요."
- **서브카피**: 자료의 가치 한 줄 요약
  - 예: "10년차 진로상담사가 정리한 셀프 진단 워크북을 무료로 드립니다."
- **이메일 입력폼 + CTA 버튼** (즉시 노출, 스크롤 없이 보이게)
  - 입력 필드: 이메일 1개 (선택적으로 이름). **필드는 최소화** — 필드 1개당 전환율 하락.
  - CTA 문구: "제출" ❌ → **"무료 워크북 받기"** ⭕ (행동+보상 명시)
- **보조 신뢰 요소**: "지금까지 1,200명이 받아갔어요" / 자료 목업 이미지

### ② 공감 섹션 — "이런 고민 있으신가요?"
- 체크리스트 형태로 타깃의 고민 3~5개 나열
  - "출근길마다 '이 길이 맞나' 싶다"
  - "이직하고 싶지만 뭘 준비해야 할지 모르겠다"
  - "적성검사는 해봤지만 달라진 게 없다"
- 목적: "이거 내 얘기다" → 스크롤 지속 유도

### ③ 자료 소개 — "이 자료에서 얻을 수 있는 것"
- 자료 목차/미리보기 이미지 + 핵심 혜택 3~4개 (기능이 아닌 **결과** 중심)
  - "내 강점과 가치관을 한 장으로 정리"
  - "지금 당장 할 수 있는 액션플랜 도출"
- 페이지 수, 구성 등 구체적 스펙 명시 → 실물감 부여

### ④ 상담사 소개 (신뢰 구축)
- 프로필 사진 + 이름 + 한 줄 포지셔닝
- 자격/경력: 상담 건수, 경력 연차, 자격증, 출강/기고 이력
- 짧은 스토리: "왜 성인 진로상담을 하게 되었는가" (2~3문장)

### ⑤ 후기/사회적 증거
- 상담 or 자료 이용 후기 2~3개 (실명 일부 마스킹: 김○○, 34세 마케터)
- 숫자 강조: 누적 상담 시간, 만족도 등

### ⑥ 받는 방법 안내 (심리적 장벽 제거)
- 3단계 안내: 이메일 입력 → 메일함 확인 → 자료 다운로드
- "스팸 없어요. 원치 않으면 언제든 수신거부 가능해요." 문구로 이메일 제공 불안 해소

### ⑦ 최종 CTA (하단 폼 반복)
- 헤드라인 변형: "지금 시작하지 않으면, 1년 뒤에도 같은 고민을 하고 있을 거예요."
- 이메일 폼 + CTA 버튼 재노출
- (선택) FAQ 2~3개: "정말 무료인가요?" / "자료는 언제 오나요?"

### ⑧ 푸터
- 상호/연락처, 개인정보처리방침 링크, SNS 링크

## 5. 폼 & 개인정보 처리

- **필수**: 개인정보 수집·이용 동의 체크박스 (수집항목: 이메일 / 목적: 자료 발송 및 뉴스레터 / 보유기간 명시) — 개인정보보호법 준수
- 제출 후 처리:
  - 성공 시: 폼 자리에 "신청 완료! 메일함을 확인해주세요" 메시지 (페이지 이탈 없이)
  - 이메일 형식 검증 + 오류 메시지 인라인 표시
- 연동 후보: 스티비, Mailchimp, 폼스프리(Formspree), Google Forms API 등

## 6. 디자인 방향

- **톤**: 따뜻하고 신뢰감 있는 전문가 톤. 차분한 배경 + 포인트 컬러 1개(딥그린 or 네이비 계열 추천 — 안정/신뢰 연상)
- **타이포**: Pretendard, 큰 헤드라인 중심
- **CTA 버튼**: 페이지에서 가장 눈에 띄는 색 (포인트 컬러의 보색 or 고채도)
- **모바일 우선**: 유입 대부분이 SNS/광고 → 모바일. 폼은 모바일에서 한 손 조작 가능하게
- 이미지: 자료 목업 1장 + 상담사 프로필 1장이면 충분. 과한 스톡이미지 지양

## 7. 카피라이팅 원칙 요약

1. 헤드라인은 자료 자랑이 아니라 **타깃의 고민**으로 시작
2. CTA는 항상 "받기/시작하기" 등 **보상이 보이는 동사**
3. 혜택은 기능("20페이지 PDF")이 아닌 결과("방향이 정리됩니다")로
4. 숫자를 쓸 수 있는 곳엔 반드시 숫자 (경력, 상담 건수, 페이지 수)

## 8. 구현 계획 (다음 단계)

현재 저장소의 Vite + React + Tailwind 환경에서:
1. 단일 페이지 컴포넌트로 섹션 ①~⑧ 구현
2. 이메일 폼 컴포넌트 (검증 + 제출 상태 관리)
3. 폼 백엔드 연동 (스티비/Formspree 등 결정 필요)
4. 반응형 + 접근성(라벨, 대비) 점검
5. OG 태그 / 메타 설정 (SNS 공유 최적화)
