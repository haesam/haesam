# 라이언 커리어랩 — 디자인 가이드

무료자료 신청 랜딩페이지의 시각 시스템 정의. 모든 신규 화면·배너·자료 표지는 이 가이드를 따른다.

## 1. 브랜드 성격

| 키워드 | 의미 |
|---|---|
| 신뢰 | 10년차 전문가. 과장 없이 차분하게 |
| 온기 | 상담사의 따뜻함. 차갑거나 기업적이지 않게 |
| 명료 | "방향을 정리해준다"는 약속처럼, 화면도 정돈되게 |

톤앤매너 한 줄 요약: **"조용히 신뢰가 쌓이는 상담실"** — 화려한 마케팅 페이지가 아니라 전문가의 서재 같은 인상.

## 2. 컬러 팔레트

| 역할 | 이름 | HEX | 용도 |
|---|---|---|---|
| Primary | Forest | `#1B4332` | 헤드라인, 히어로 배경, 푸터 |
| Primary Light | Sage | `#2D6A4F` | 보조 배경, 아이콘, 호버 |
| Accent (CTA 전용) | Amber | `#F59E0B` | CTA 버튼, 핵심 강조. **CTA 외 남용 금지** |
| Background | Cream | `#FAF7F2` | 페이지 기본 배경 |
| Surface | White | `#FFFFFF` | 카드, 폼 배경 |
| Text | Ink | `#1C1917` | 본문 텍스트 |
| Text Muted | Stone | `#78716C` | 보조 텍스트, 캡션 |
| Line | Sand | `#E7E0D5` | 구분선, 카드 테두리 |

규칙:
- 한 화면에서 Amber는 **CTA 버튼과 핵심 숫자 강조에만** 사용한다. 여러 곳에 쓰면 CTA가 죽는다.
- Forest 배경 위 텍스트는 Cream(`#FAF7F2`) 또는 White만 사용 (명도 대비 확보).
- 그라데이션·네온·그림자 남용 금지. 그림자는 카드에 `0 1px 3px rgba(0,0,0,.06)` 수준까지만.

## 3. 타이포그래피

- **서체**: Pretendard (한글/영문 겸용). fallback: `-apple-system, sans-serif`
- 자간: 한글 헤드라인 `-0.02em`, 본문 `-0.01em`

| 스타일 | 크기 (모바일 / 데스크톱) | 굵기 | 용도 |
|---|---|---|---|
| Display | 32px / 52px | 700 | 히어로 헤드라인 |
| H2 | 24px / 36px | 700 | 섹션 제목 |
| H3 | 18px / 20px | 600 | 카드 제목 |
| Body | 16px / 17px | 400 | 본문 (행간 1.7) |
| Caption | 13px / 14px | 400 | 보조 문구, 법적 고지 |

규칙: 헤드라인에서 강조할 단어는 색(Amber) 또는 밑줄 하나만. 굵기+색+크기 동시 강조 금지.

## 4. 레이아웃 & 여백

- 콘텐츠 최대 폭: **1080px** (본문성 섹션은 720px)
- 섹션 상하 여백: 모바일 64px / 데스크톱 96px
- 기본 간격 단위: 4px 배수 (Tailwind 기본 스케일 사용)
- 모바일 좌우 패딩: 20px
- **모바일 퍼스트**: 모든 섹션은 1열 → md(768px)부터 다열

## 5. 컴포넌트

### CTA 버튼 (Primary)
- 배경 Amber, 텍스트 Ink(진한 색이 가독성↑), radius 12px, 높이 52px(모바일 56px)
- 문구는 항상 "보상 + 동사": "무료 워크북 받기"
- hover: 밝기 -6%, 살짝 위로 (translateY(-1px))
- 한 화면(뷰포트)에 Primary CTA는 1개만

### 이메일 폼
- 필드: 이메일 1개. placeholder "이메일 주소를 입력하세요"
- 필드 높이 = 버튼 높이 (52px), radius 12px, 테두리 Sand → focus 시 Sage 2px
- 데스크톱: 필드+버튼 가로 배치 / 모바일: 세로 스택
- 동의 체크박스는 폼 바로 아래 Caption 크기
- 오류: 필드 테두리 `#DC2626` + 하단 인라인 메시지. alert() 금지
- 성공: 폼 영역이 완료 메시지 카드로 전환 (페이지 이동 없음)

### 카드
- 배경 White, 테두리 1px Sand, radius 16px, 패딩 24~32px
- 아이콘은 Sage 단색 라인 아이콘으로 통일

### 후기 카드
- 인용 부호 + 본문 + 하단에 "김○○ · 34세 · 마케터" 형식 (이름 마스킹)

## 6. 이미지 & 아이콘

- 사진: 따뜻한 자연광 톤. 차가운 오피스 스톡사진 금지
- 자료 목업: 실물감 있는 표지 이미지 1장 (기울임 5° 이내)
- 아이콘: 1.5px 굵기의 라인 아이콘, Sage 단색
- 일러스트를 쓴다면 라인 스타일 1종으로 통일 (혼용 금지)

## 7. 모션

- 원칙: "느껴지되 눈치채지 못하게". 과한 모션은 신뢰를 깎는다
- 섹션 진입: opacity 0→1 + translateY 16px→0, 0.5s ease-out, 1회만
- CTA hover 외 반복 애니메이션 금지 (히어로의 스크롤 힌트 제외)
- `prefers-reduced-motion` 존중

## 8. 접근성 체크리스트

- [ ] 텍스트 대비 WCAG AA (4.5:1) 이상 — Amber 위 텍스트는 반드시 Ink
- [ ] 폼 input에 label 연결 (시각적으로 숨겨도 markup에는 존재)
- [ ] 오류 메시지는 색상 외 텍스트로도 전달
- [ ] 키보드만으로 폼 제출 가능, focus ring 제거 금지
- [ ] 이미지 alt 텍스트 필수

## 9. Do & Don't

| Do | Don't |
|---|---|
| CTA는 페이지에서 유일하게 튀는 색 | 무지개색 그라데이션 헤드라인 |
| 숫자로 신뢰 표현 (2,400건 상담) | "최고의", "국내 1위" 같은 근거 없는 수식 |
| 여백으로 고급스러움 표현 | 팝업·카운트다운·깜빡이는 배지 |
| 상담사 실제 사진 톤 유지 | 과보정된 스톡 인물 사진 |
