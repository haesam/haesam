## 구성 섹션

1. **네비게이션** — 스크롤 시 글래스모피즘 처리되는 고정 필 내비 + 모바일 풀스크린 오버레이 메뉴
2. **히어로 (400vh 스크롤 스크럽)** — B·X 초대형 타이포 사이 동심원 4개가 스크롤에 따라 확대, 두 단계 헤드라인 시퀀스 + CTA
3. **서비스 (300vh 스태킹 카드)** — 스크롤에 따라 카드 3장이 차례로 쌓이는 인터랙션
4. **포트폴리오** — 호버/탭으로 확장되는 아코디언 갤러리 (프로젝트 5개)
5. **푸터** — `mix-blend-mode` 텍스트 마스크로 글자 안에 비디오가 재생되는 "LET'S TALK."

## 편집 가능 설정

블록 설정 패널의 **데이터** 탭에서 로고·메뉴·문구·비디오·프로젝트 목록을,
**디자인** 탭에서 브랜드 컬러 4종과 데스크톱/모바일 여백을 수정할 수 있습니다.
